# GitHub PR & Issue Assistant

An AI-powered agent that analyzes GitHub Pull Requests (PRs) and Issues by simply providing their URLs. It automatically summarizes the content, reviews changes, and provides a verdict on whether a PR is ready to merge into the `main` branch.

## Features

- **Automated Summarization:** Generates concise summaries of PRs and Issues.
- **PR Analysis:** Examines code changes and diffs.
- **Merge Verdict:** Provides an AI-generated recommendation on whether to merge a PR.
- **URL-Based Workflow:** Analyze PRs or Issues by providing their GitHub URLs.

## Tech Stack

- Python
- LangChain
- Large Language Models (LLMs)
- GitHub API

## Getting Started

1. Clone the repository.
2. Install dependencies.
3. Configure the required environment variables.
4. Run the application and provide a GitHub PR or Issue URL.

## Goal

To simplify code reviews and issue analysis using AI, helping developers make faster and more informed decisions.

**Note:** Merge recommendations are AI-generated and should be reviewed by a developer before merging.
